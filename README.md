# Yutai Wi-Fi

通过局域网 MiIO 接入宇泰 Wi-Fi 插座的 Home Assistant 自定义集成。
项目独立于 `ha-yutai-ble`，不复用 BLE 协议，不要求米家云端常驻登录。

## 当前状态

`0.1.1` 源码已发布到 [GitHub](https://github.com/jsdfhasuh/ha-yutai-wifi)。
通过 HACS 自定义仓库安装；尚未申请 HACS 默认列表收录。
HACS 自定义仓库安装与 HACS 默认商店收录是两件不同的事。

当前验证：CI 的离线测试、HA 2026.10.4 框架测试、hassfest 和 HACS 检查均通过。
已通过 HACS 在 HA 2026.10.4 中添加一台实机，配置项已加载，开关状态与四项计量实体可读。
本轮安装没有发送开关控制命令；模拟测试包含空闲后重新握手回归用例。
完整边界见 [验收记录](docs/ACCEPTANCE.md)。

`0.1.1` 修复了 `0.1.0` 首次读取正常、空闲后轮询超时的问题：每次操作前重新握手
以同步 MiIO 通信状态，仍不自动重试开关写入。首次读取成功不足以证明持续轮询正常。

支持的型号仅为 `yutai.plug.jdls1`，已核对固件 `1.1.1` 的基础协议。
同型号可添加多台；同品牌其他型号及其他品牌必须单独验证和增加模型适配，
不会通过默认映射尝试控制未知设备。

## 首版功能

- 每台设备一个独立配置项，单独保存 IP 和 Token；不含写死的用户 IP、MAC 或 Token。
- UI 添加、按设备身份去重；通过“重新配置”更新 IP 或 Token，拒绝替换成另一台设备。
- 1 个电源开关，4 个传感器：电压 V、电流 A、功率 W、设备上报电量 kWh。
- 默认每 60 秒轮询；手动开关命令后立即读取确认，不在启动或恢复连接时自动切换电源。
- 通信失败显示不可用，单项计量失败不会伪造为 0，命令未确认时显示错误。
- 多设备状态、命令锁和实体 ID 相互独立；同一设备的轮询和控制串行执行。
- 中英文界面和脱敏诊断，不提供任意命令接口。

电量累计周期、掉电保存、复位/溢出尚未确认，所以电量没有 `total_increasing`
状态类，不直接进入 HA 能源面板。读数是否准确仍需带载和独立仪表验收。
首版不写入原生定时、循环、点动、童锁、功率保护或上电状态，不更新固件。
可以在 HA 中对开关编写自动化，但它依赖 HA 运行，不等于插座内置定时。

## HACS 安装流程

1. HACS -> 右上角菜单 -> 自定义存储库。
2. 输入 `https://github.com/jsdfhasuh/ha-yutai-wifi`，类别选择“集成”，下载 Yutai Wi-Fi。
3. 按 HA/HACS 提示重启 Home Assistant，加载集成代码。
4. 设置 -> 设备与服务 -> 添加集成 -> Yutai Wi-Fi。
5. 输入这一台插座的局域网 IPv4、MiIO Token 和可选名称。
6. 添加下一台时重复第 4、5 步，无需修改代码或复制一套集成。

需要 HA 2026.10.4 或更新兼容版本；更低版本暂未验证。HA 主机需能访问插座 UDP 54321。
首版使用 `main` 分支安装和更新，暂未提供独立 Release；安装页显示提交版本是正常现象。
建议 DHCP 地址保留；IP 改变后使用“重新配置”。添加过程只验证身份并读取属性。
依赖下载和 HACS 更新需要网络；运行期不调用小米云 API。
这不代表该型号已经通过持续断外网实机验收。

## Token 与隐私

Token 获取工具独立于这个公开仓库。已有 Windows 加密 Token 文件不会被打包或上传。
每台新插座在获取工具中单独选择，再在 HA 中单独添加；不要把 Token 发到聊天、Issue 或截图。
HA 配置项需要保存 Token，HA 配置存储不是 Windows DPAPI 加密；应保护 HA 文件系统与备份。
重新配置时 Token 不回填到表单，留空可保留旧值。
集成诊断只返回型号、轮询周期、读取成功状态和可用字段名，不返回 IP、MAC、Token、名称或用电值。
依赖库的原始日志仅在本集成执行网络请求的线程范围内抑制，不全局关闭其他集成日志。

## 开发和验证

本地纯协议和包结构测试（不接触设备）：

```powershell
python -B -m unittest discover -s tests -v
python -B tools/build_release.py
```

`tests/test_ha.py` 使用真实 HA 类及模拟设备，不加载生产配置；没有 HA 运行库时会明确跳过。
CI 分别运行纯测试和安装 HA 后的框架测试，并运行 hassfest/HACS 检查。
离线测试通过不等于 HACS 实际安装、断网运行或物理带载验收通过。

发布打包器只从 `custom_components/yutai_wifi/` 的明确白名单生成 ZIP，
不读取上级目录、认证工具、研究插件包或设备快照。没有自动发布工作流。
发布和生产安装必须另行确认。

集成图标为本项目原创的通用插头图形，不是厂商商标。可用 Pillow 运行
`python tools/generate_brand.py` 重新生成；Pillow 不是集成运行依赖。

新增型号时在 `models.py` 添加精确型号配置及测试，先验证身份、只读属性和单位，
再单独授权实机开关测试。不得把未验证型号绑定到 JDLS1 配置。
